# 计算机网络_试题_网传版

### 2010-2011学年度第二学期华中科技大学《计算机网络技术与应用》试卷(A卷)

-  选择题及解析
  
  ### 1. 下列关于计算机网络的描述，错误的是( )
  
  A) 主要的目的是实现计算机资源的共享 
  B) 联网的计算机可以访问本地和远程资源 
  C) 联网的计算机之间有明显的主从关系 
  D) 联网的计算机遵循相同的网络协议 
  **答案：C** 
  **解析**： 
  计算机网络的核心特征包括： 
- 资源共享（硬件、软件、数据，对应选项A）； 
- 节点独立性：联网计算机是平等的“自治系统”，无明显主从关系（选项C错误）； 
- 可访问本地（自身资源）和远程（其他节点资源，对应选项B）； 
- 协议一致性：所有节点遵循统一网络协议（如TCP/IP，对应选项D）。 
  
  ### 2. 下列不属于网络协议三要素的是( )
  
  A) 语法 B) 语义 C) 接口 D) 时序 
  **答案：C** 
  **解析**： 
  网络协议的三要素是实现通信的核心规则，具体定义如下： 
- **语法**：规定数据的格式（如帧结构、字段长度）； 
- **语义**：规定数据的含义（如“0x01”表示“请求连接”）； 
- **时序（同步）**：规定通信的顺序（如“先发送请求，再接收响应”）； 
  “接口”是分层体系中相邻层的交互边界，不属于协议三要素（选项C）。 
  
  ### 3. 计算机网络通信在不同的状态使用不同的地址名称。通过下列哪个地址来选择进程？( )
  
  A) 端口地址 B) IP地址 C) MAC地址 D) 域名 
  **答案：A** 
  **解析**： 
  不同地址的功能分工明确，对应不同层级的“定位目标”： 
- **端口地址**：传输层地址，用于定位主机内的特定进程（如80端口对应HTTP服务，选项A）； 
- **IP地址**：网络层地址，用于定位互联网中的主机（选项B）； 
- **MAC地址**：数据链路层地址，用于定位局域网内的物理设备（选项C）； 
- **域名**：应用层标识符，通过DNS映射为IP地址，间接定位主机（选项D）。 
  
  ### 4. OSI参考模型的物理层负责下列哪一种功能？( )
  
  A) 格式化报文 B) 为数据选择通过网络的路由 
  C) 定义连接到介质的特征 D) 提供远程文件访问能力 
  **答案：C** 
  **解析**： 
  OSI七层模型各层功能分工严格，物理层的核心是“实现物理介质上的信号传输”，具体功能包括： 
- 定义物理介质的特征（如线缆类型、接口形状、信号电平，选项C）； 
- 选项A（格式化报文）是**表示层**功能； 
- 选项B（路由选择）是**网络层**功能； 
- 选项D（远程文件访问）是**应用层**功能（如FTP协议）。 
  
  ### 5. 下列关于OSI参考模型的描述，正确的是( )
  
  A) 不同节点的不同层次间通过协议通信 
  B) 高层需要知道低层的实现方法 
  C) 高层通过接口为低层提供服务 
  D) 不同节点的同等层具有相同功能 
  **答案：D** 
  **解析**： 
  OSI模型的核心设计原则是“分层解耦”，关键特性如下： 
- 选项A错误：仅**同一节点的同等层**（如A节点的传输层与B节点的传输层）通过协议通信，不同层次间不直接通信； 
- 选项B错误：高层通过“接口”使用低层服务，无需知道低层的实现细节（如应用层无需知道物理层是用网线还是无线）； 
- 选项C错误：**低层为高层提供服务**（如物理层为数据链路层提供比特流传输服务），方向相反； 
- 选项D正确：同等层的设计目标一致（如所有节点的网络层都负责路由选择），功能相同。 
  
  ### 6. 在TCP/IP参考模型中，与OSI参考模型的网络层对应的是( )
  
  A) 主机-网络层 B) 传输层 C) 互联层 D) 应用层 
  **答案：C** 
  **解析**： 
  TCP/IP参考模型（四层）与OSI参考模型（七层）的对应关系如下： 
  
  | TCP/IP四层模型                       | 对应OSI七层模型   | 核心功能          |
  | -------------------------------- | ----------- | ------------- |
  | 应用层                              | 应用层+表示层+会话层 | 提供应用服务（如HTTP） |
  | 传输层                              | 传输层         | 端到端可靠传输（如TCP） |
  | **互联层**                          | **网络层**     | 路由选择、IP寻址     |
  | 主机-网络层                           | 数据链路层+物理层   | 物理介质访问        |
  | 因此，TCP/IP的“互联层”对应OSI的“网络层”（选项C）。 |             |               |
  
  ### 7. 在TCP/IP参考模型中，不属于应用层的协议是( )
  
  A) ARP B) HTTP C) SMTP D) FTP 
  **答案：A** 
  **解析**： 
  TCP/IP各层协议分类如下： 
- **应用层**：HTTP（网页传输）、SMTP（邮件发送）、FTP（文件传输），对应选项B、C、D； 
- **网络层**：ARP（地址解析协议，将IP映射为MAC）、IP、ICMP，选项A属于网络层，不属于应用层。 
  
  ### 8. 下列e-mail地址合法的是( )
  
  A) jisuanji@ B) jisuanji@hust.edu.cn C) @jisuanji D) .hust.jisuanji 
  **答案：B** 
  **解析**： 
  合法邮箱地址的格式为：`用户名@域名`，其中： 
- 用户名：由字母、数字、下划线等组成，不能以特殊字符开头/结尾； 
- `@`：必须存在，且仅出现一次； 
- 域名：需符合域名规范（如`hust.edu.cn`是华中科技大学的域名）； 
  选项A（无域名）、C（无用户名）、D（无`@`和用户名）均不合法，仅选项B符合格式。 
  
  ### 9. FTP协议实现的基本功能是( )
  
  A) 文件传输 B) 域名解析 C) 邮件接收 D) 网络管理 
  **答案：A** 
  **解析**： 
  常见协议的核心功能： 
- **FTP（文件传输协议）**：实现客户端与服务器之间的文件上传/下载（选项A）； 
- **DNS（域名系统）**：实现域名到IP地址的映射（域名解析，选项B）； 
- **POP3/IMAP**：实现邮件接收（选项C）； 
- **SNMP（简单网络管理协议）**：实现网络设备监控与管理（选项D）。 
  
  ### 10. 在分层的体系结构中，同一节点相邻层间进行交互是依据( )
  
  A) 协议 B) 层次 C) 接口和服务 D) 封装 
  **答案：C** 
  **解析**： 
  分层体系中“层间交互”与“层内通信”的区别： 
- **同一节点相邻层**：通过“接口”交互，低层通过接口为高层提供“服务”（如数据链路层通过接口为网络层提供帧传输服务，选项C）； 
- **不同节点同等层**：通过“协议”通信（如A节点传输层与B节点传输层通过TCP协议通信，选项A）； 
- “层次”是体系结构的划分单位，“封装”是数据在层间传递的处理方式（如数据链路层将IP数据包封装为帧），均不直接用于相邻层交互。 
  
  ### 11. 物理层上信息传输的基本单位称为( )
  
  A) 段 B) 位 C) 帧 D) 报文 
  **答案：B** 
  **解析**： 
  OSI各层数据传输的基本单位（PDU，协议数据单元）： 
  
  | OSI层次                 | 传输单位                             | 说明              |
  | --------------------- | -------------------------------- | --------------- |
  | 物理层                   | **位（bit）**                       | 最小单位，0/1二进制信号   |
  | 数据链路层                 | 帧（frame）                         | 包含MAC地址、校验字段等   |
  | 传输层                   | 段（segment，TCP）/数据报（datagram，UDP） | 包含端口号、序号等       |
  | 应用层                   | 报文（message）                      | 包含应用数据（如HTTP请求） |
  | 因此，物理层的传输单位是“位”（选项B）。 |                                  |                 |
  
  ### 12. 在广播域中，一个节点广播信息，其他节点都可以接收到，其原因是( )
  
  A) 一个节点对应一个通信信道 
  B) 多个节点共享一个通信信道 
  C) 多个节点对应多个通信信道 
  D) 多个节点共享多个通信信道 
  **答案：B** 
  **解析**： 
  广播域的核心特征是“共享信道”： 
- 共享信道（如早期的集线器网络）中，所有节点共用一条物理信道，一个节点发送广播信息时，信号会覆盖整个信道，所有节点均可接收（选项B）； 
- 点对点信道（如交换机的端口间链路）中，一个节点对应一条独立信道，信息仅传递给目标节点，无法广播（选项A）； 
  选项C、D的“多个信道共享”不符合广播域的定义。 
  
  ### 13. DNS协议主要用于实现下列哪种网络服务的功能？( )
  
  A) 域名到IP地址的映射 
  B) IP地址到域名的映射 
  C) MAC地址到IP地址的映射 
  D) IP地址到MAC地址的映射 
  **答案：A** 
  **解析**： 
  DNS的核心功能是“域名与IP地址的双向映射”，但“主要功能”是正向解析： 
- **正向解析**：将用户易记的域名（如`www.hust.edu.cn`）映射为计算机可识别的IP地址（如`202.114.64.1`），这是用户访问互联网的主要场景（选项A）； 
- **反向解析**：将IP地址映射为域名（如用于邮件服务器验证，选项B），属于次要功能； 
- 选项C（MAC到IP）无对应协议，选项D（IP到MAC）是ARP协议的功能。 
  
  ### 14. 在交换式以太网中实现虚拟局域网（VLAN）时，不包括( )
  
  A) 基于端口的虚拟局域网 
  B) 基于MAC地址的虚拟局域网 
  C) 基于IP地址的虚拟局域网 
  D) 基于域名的虚拟局域网 
  **答案：D** 
  **解析**： 
  VLAN（虚拟局域网）的常见划分方式： 
- **基于端口**：按交换机端口分组（如端口1-8为VLAN 10），最常用（选项A）； 
- **基于MAC地址**：按设备的MAC地址分组（适合移动设备，选项B）； 
- **基于IP地址**：按主机的IP地址或子网分组（适合动态网络，选项C）； 
  目前无“基于域名的VLAN划分”方式（选项D），因域名需通过DNS解析为IP，无法直接用于VLAN分组。 
  
  ### 15. 下列关于交换式局域网的描述，错误的是( )
  
  A) 核心设备是局域网交换机 
  B) 需通过广播方式发送数据 
  C) 通常可提供虚拟局域网（VLAN）服务 
  D) 支持多节点之间的并发连接 
  **答案：B** 
  **解析**： 
  交换式局域网（基于交换机）与共享式局域网（基于集线器）的核心区别： 
- 选项A正确：交换式局域网的核心设备是交换机； 
- 选项B错误：交换机通过“MAC地址表”实现点对点通信，仅在目标MAC未知时发送一次广播（地址学习），无需像集线器那样始终广播； 
- 选项C正确：交换机支持VLAN划分，可隔离广播域； 
- 选项D正确：交换机的每个端口是独立信道，支持多对节点同时通信（并发连接）。 
  
  ### 16. 在配置三层交换机时，由用户登录模式进入到特权模式，使用的命令是( )
  
  A) enable B) configure terminal 
  C) interface D) switchport 
  **答案：A** 
  **解析**： 
  三层交换机/路由器的常见模式切换命令： 
  
  | 模式切换路径                                 | 命令                           | 说明              |
  | -------------------------------------- | ---------------------------- | --------------- |
  | 用户模式（User EXEC）→ 特权模式（Privileged EXEC） | **enable**                   | 进入特权模式，需密码验证    |
  | 特权模式 → 全局配置模式                          | configure terminal           | 用于全局参数配置（选项B）   |
  | 全局配置模式 → 接口模式                          | interface <接口名>              | 用于接口参数配置（选项C）   |
  | 接口模式 → 接入模式/ trunk模式                   | switchport mode access/trunk | 配置VLAN端口模式（选项D） |
  | 因此，用户模式到特权模式的命令是`enable`（选项A）。         |                              |                 |
  
  ### 17. 下列关于路由器的说法中，错误的是( )
  
  A) 路由器可以隔离子网，抑制广播风暴 
  B) 路由器可以实现网络地址转换（NAT） 
  C) 路由器可以提供可靠性不同的多条路由选择 
  D) 路由器只能实现点对点的传输 
  **答案：D** 
  **解析**： 
  路由器的核心功能： 
- 选项A正确：路由器不转发广播包，可将网络划分为多个子网，抑制广播风暴； 
- 选项B正确：路由器支持NAT功能，将私有IP转换为公有IP，实现内网访问互联网； 
- 选项C正确：路由器通过路由表存储多条路由（如静态路由、动态路由），可根据链路可靠性（如带宽、延迟）选择路径； 
- 选项D错误：路由器支持“点对多点”传输（如一个路由器连接多个子网），并非只能点对点。 
  
  ### 18. 内部网关协议（IGP）是在一个自治系统（AS）内部使用的路由选择协议，下列属于IGP的是( )
  
  A) BGP B) RIP C) AS D) BIP 
  **答案：B** 
  **解析**： 
  路由协议按作用范围分为IGP和EGP： 
- **IGP（内部网关协议）**：用于自治系统（AS）内部的路由选择，常见协议有RIP（路由信息协议）、OSPF（开放式最短路径优先），选项B属于IGP； 
- **EGP（外部网关协议）**：用于不同自治系统之间的路由选择，常见协议有BGP（边界网关协议，选项A属于EGP）； 
- 选项C（AS）是“自治系统”的缩写，不是协议；选项D（BIP）无对应路由协议。 
  
  ### 19. 下列属于路由表的产生方式的是( )
  
  A) 通过手工配置添加路由（静态路由） 
  B) 通过运行动态路由协议自动学习产生（动态路由） 
  C) 路由器的直连网段自动生成（直连路由） 
  D) 以上都是 
  **答案：D** 
  **解析**： 
  路由器的路由表条目主要有三种来源： 
1. **直连路由**：路由器接口配置IP地址并启用后，自动生成该接口所在网段的路由条目； 
2. **静态路由**：管理员通过手工配置命令（如`ip route`）添加的路由条目； 
3. **动态路由**：路由器通过运行动态路由协议（如RIP、OSPF）从其他路由器自动学习的路由条目； 
   因此，选项A、B、C均属于路由表的产生方式，答案为D。 
   
   ### 20. 在为路由器配置静态路由时使用的命令是( )
   
   A) ip route B) ip routing 
   C) route D) routing 
   **答案：A** 
   **解析**： 
   路由器静态路由配置的核心命令： 
- **ip route**：在全局配置模式下，用于添加静态路由条目，格式为`ip route <目标网络> <子网掩码> <下一跳IP/出接口>`（选项A）； 
- **ip routing**：用于开启路由器的IP路由功能（默认开启，选项B）； 
- **route**：是Windows操作系统的命令（用于配置主机路由，选项C）； 
- **routing**：不是路由器的有效配置命令（选项D）。 
  
  ### 21. 下列关于Internet的描述，错误的是( )
  
  A) 是一个信息资源网 
  B) 是一个局域网 
  C) 是一个互联网（Internetwork） 
  D) 运行TCP/IP协议 
  **答案：B** 
  **解析**： 
  Internet的核心特性： 
- 选项A正确：Internet是全球最大的信息资源网，包含海量数据、服务（如网页、邮件）； 
- 选项B错误：Internet是“互联网”（多个局域网、广域网通过路由器互联形成的大网络），并非单一局域网； 
- 选项C正确：Internet的本质是“互联的网络”（Internetwork的缩写）； 
- 选项D正确：TCP/IP协议是Internet的核心协议，所有接入节点必须遵循。 
  
  ### 22. 下列IP地址中，一个合法的C类IP地址为( )
  
  A) 10.1.1.1 B) 172.16.1.1 C) 224.0.0.1 D) 192.168.1.56 
  **答案：D** 
  **解析**： 
  IP地址（IPv4）按首段字节范围分为五类，其中A、B、C类为常用单播地址： 
  
  | IP地址类别                                    | 首段字节范围  | 子网掩码          | 示例                |
  | ----------------------------------------- | ------- | ------------- | ----------------- |
  | A类                                        | 1-126   | 255.0.0.0     | 10.1.1.1（选项A）     |
  | B类                                        | 128-191 | 255.255.0.0   | 172.16.1.1（选项B）   |
  | C类                                        | 192-223 | 255.255.255.0 | 192.168.1.56（选项D） |
  | D类（组播）                                    | 224-239 | 无固定子网掩码       | 224.0.0.1（选项C）    |
  | 因此，选项D是合法的C类IP地址，选项A（A类）、B（B类）、C（D类）均不符合。 |         |               |                   |



### 华中科技大学2012年5月《计算机网络》试卷(A卷)

### 1. 计算机网络的混合模型分为___层，其中网络层的主要功能是___。

**答案**：5；路由选择、分组转发、IP寻址（任答核心功能即可） 
**解析**： 

- 计算机网络常用“五层混合模型”（融合OSI七层与TCP/IP四层的优势），层级从下到上为：物理层、数据链路层、网络层、传输层、应用层。

  ### 4. T1标准可以同时传输___路音频信号，传输的数据速率为___Mb/s。
  
  **答案**：24；1.544 
  **解析**：

  ### 5. 物理层常用的信道复用技术有多种，常用的四种分别为___、___、___和___。
  
  **答案**：频分复用（FDM）；时分复用（TDM）；码分复用（CDM/CDMA）；波分复用（WDM） 
  **解析**： 
  复用技术的核心是“共享一条信道传输多路信号”，四种技术的区别如下： 
- **FDM**：按“频率”划分信道（如收音机不同频段对应不同电台），信号同时传输，需保留保护频段避免干扰。 
- **TDM**：按“时间”划分信道（如T1标准），信号分时传输，需同步时钟确保时隙对齐。 
- **CDM**：按“编码”划分信道（如手机CDMA网络），多路信号用不同编码叠加传输，接收端通过专属编码解调。 
- **WDM**：按“波长”划分信道（如光纤通信），本质是光信号的FDM，可传输大量数据。 
  
  ### 6. 数据链路层成帧（帧同步）的主要方法有四种，分别是___、___、___和___。
  
  **答案**：字符计数法；字符填充的首尾定界符法；比特填充的首尾标志法；违规编码法 
  **解析**： 
  “成帧”是将物理层的比特流划分为独立的数据帧，四种方法的核心是“标记帧的首尾边界”： 
- **字符计数法**：帧头部记录帧内字符总数，接收端按计数截取帧（缺点：计数错误会导致后续帧同步失败）。 
- **字符填充法**：用特定字符（如SOH、EOT）标记帧首尾，若数据中含定界字符，需在其前加填充字符（如ESC）。 
- **比特填充法**：用固定比特串（如HDLC的01111110）标记帧首尾，数据中每出现5个连续1，就填充1个0（避免与定界符混淆）。 
- **违规编码法**：利用物理层不允许的编码表示帧首尾（如曼彻斯特编码中“高-高”电平代表帧边界），无需填充。 
  
  ### 7. 若待发送的数据比特序列为“110111011”，采用CRC编码技术对其进行抗干扰编码，生成多项式为1011，则抗干扰编码为___。
  
  **答案**：110111011101 
  **解析**： 
  CRC（循环冗余校验）编码步骤如下： 
1. **确定参数**：数据M=110111011（9位），生成多项式G=1011（4位，r=3，需补3个0到M后）。 
2. **计算M×x³**：在M后补3个0，得到110111011000（12位）。 
3. **模2除法**：用110111011000与1011做“异或运算”（无借位减法），余数即为FCS（帧检验序列）。 
- 除法结果：余数=101（3位，不足r位补前导0）。 
4. **抗干扰编码**：数据M + FCS = 110111011 + 101 = 110111011101。 
   
   ### 8. 一个电话话路的频带范围为900Hz-4000Hz，信道的信噪比为30分贝，根据香农公式，该信道上的最大传输速度为___bps。
   
   **答案**：31000（或约31kbps） 
   **解析**： 
   香农公式是“信道最大传输速率”的计算依据，公式为： 
   **C = W × log₂(1 + S/N)** 
- **W（带宽）**：信道最高频率 - 最低频率 = 4000Hz - 900Hz = 3100Hz。 
- **S/N（信噪比）**：分贝（dB）与信噪比的换算关系为 **dB = 10×log₁₀(S/N)**，代入30dB得：30 = 10×log₁₀(S/N) → S/N = 10³ = 1000。 
- **计算C**：C = 3100 × log₂(1+1000) ≈ 3100 × 10 = 31000bps（因log₂1024=10，1001≈1024，近似为10）。

  ### 10. 某单位分配到一个IP地址，其网络号（Net-ID）为：213.15.74.0，根据该单位的具体情况，需要划分六个子网，则其子网掩码应为___。

   ### 题目4：说明IPv4向IPv6过渡的主要技术方式及适用场景
   
   **答案**： 
   IPv4向IPv6过渡的核心技术有三种： 
4. **双栈技术**：设备同时支持IPv4和IPv6协议栈，根据目标地址自动选择协议通信。 
- 适用场景：网络设备（路由器、服务器）渐进式升级，同时支持IPv4和IPv6用户。 
2. **隧道技术**：将IPv6数据包封装在IPv4数据包中，通过IPv4网络传输，到达目标后解封装。 
- 适用场景：IPv6孤岛（局部IPv6网络）通过IPv4骨干网互联，如6to4隧道、GRE隧道。 
3. **NAT64技术**：实现IPv6与IPv4地址转换，IPv6主机可通过NAT64访问IPv4资源（反之同理）。 
- 适用场景：IPv6大规模部署初期，兼容存量IPv4服务（如旧版网站、服务器）。 
  **解析**： 
  双栈是“长期演进”基础，隧道是“局部突破”手段，NAT64是“兼容过渡”保障。三者结合可实现IPv4到IPv6平滑过渡。 
  
  ### 题目5：已知待发送数据比特序列为“101101”，生成多项式为“1101”，请计算CRC校验码及最终的CRC编码序列
  
  **答案**： 
  CRC计算步骤（模2除法）： 
1. **参数确定**：数据`M=101101`（6位），生成多项式`G=1101`（4位，阶数`r=3`），在`M`后补`r`个0，得到`M'=101101000`（9位）。 
2. **模2除法**：用`M'`除以`G`，余数为CRC校验码（FCS）。 
   除法过程（异或运算，无借位）： 
- `101101000 ÷ 1101`，余数为`111`（3位）。 
3. **最终序列**：数据`M + 校验码 = 101101111`。 
   **解析**： 
   CRC通过多项式除法生成冗余码，接收端验证余数是否为0判断数据是否出错。本例中生成多项式`1101`决定除法规则，模2除法保证计算简洁，最终编码序列可检测一位或多位错误。 
   
   ### 题目6：在滑动窗口协议中，假设发送窗口大小为4，接收窗口大小为1，当前发送方已发送帧0、1、2，且帧0已收到确认，帧1、2未收到确认。请说明：
   
   （1）发送方接下来可发送的帧序号； 
   （2）若接收方收到帧3，会如何处理； 
   （3）若帧2始终未收到确认，发送方可能的原因及处理方式。
   **答案**： 
   （1）发送窗口大小为4，帧0确认后窗口右滑，可发送**帧3**（窗口范围变为1-4）。 
   （2）接收窗口期望接收帧1，收到帧3属于**失序帧**，接收方丢弃该帧，并重发对帧1的确认（重复确认），提示发送方重传帧1及后续帧。 
   （3）帧2未确认的原因：**帧2丢失**或**接收方未正确接收**（如校验错误）。发送方会因**超时重传**，在等待确认超时后重传帧2及后续未确认帧（帧2、3）。 
   **解析**： 
   滑动窗口通过“窗口机制”实现流量控制与差错控制。失序帧丢弃和超时重传是保证数据可靠传输的关键策略，如TCP协议基于滑动窗口实现可靠传输。 
   
   ### 题目7：说明动态路由表的更新机制（以RIP和OSPF为例）
   
   **答案**： 
4. **RIP（距离矢量协议）**： 
- 路由器周期性（30秒）向邻居发送**整个路由表**，邻居对比自身路由表，若发现更优路径（跳数更少）则更新。 
- 拓扑变化时通过**触发更新**快速传播变化信息，采用水平分割、毒性逆转等机制避免路由环路。 
2. **OSPF（链路状态协议）**： 
- 路由器通过**Hello报文**发现邻居，建立邻接关系后交换**链路状态信息（LSA）**（如接口带宽、开销）。 
- 基于LSA构建**链路状态数据库**，通过**Dijkstra算法**计算最短路径树，生成路由表。 
- 拓扑变化时仅发送**变化的LSA**，更新效率更高。 
  **解析**： 
  RIP适合小型网络，实现简单但收敛慢；OSPF适合大型网络，收敛快且支持多度量（如带宽），但配置复杂。动态路由协议更新机制决定了网络对拓扑变化的响应速度和稳定性。 
  
  ### 题目8：给定比特流“011111101111110”，请按照HDLC协议的比特填充规则，写出装帧后的比特序列
  
  **答案**： 
  HDLC比特填充规则：帧首尾用`01111110`标记，数据中每出现**5个连续的1**，在其后填充1个0。 
- 原比特流：`011111101111110` 
- 处理连续5个1：子序列`11111`出现2次，填充后数据为`01111101011111010` 
- 添加首尾定界符，最终序列：`01111110 01111101011111010 01111110` 
  **解析**： 
  比特填充避免数据与帧定界符混淆，保证帧同步，广泛应用于串行链路的可靠数据传输（如早期广域网链路）。 
  
  ### 题目9：已知某通信系统采用16-QAM调制，波特率为2000 Baud，求其最大数据速率；若信道带宽为4kHz，信噪比为30dB，用香农公式求最大数据速率，并对比两者结果。
  
  **答案**： 
- **16-QAM数据速率**： 
  16-QAM码元数为16，每个码元携带`log₂16 = 4`比特。 
  数据速率 = 波特率 × 每码元比特数 = `2000 × 4 = 8000 bps（8 kbps）`。 
- **香农公式计算**： 
  香农公式`C = W × log₂(1 + S/N)`，其中： 
- 带宽`W = 4kHz`， 
- 信噪比`S/N`：30dB = `10×lg(S/N)` → `S/N=1000`。 
  代入得：`C = 4000 × log₂(1+1000) ≈ 40000 bps（40 kbps）`。 
- **对比**：16-QAM速率受调制方式限制（8 kbps），香农速率受带宽和信噪比限制（40 kbps），实际传输速率由两者较小值决定。 
  **解析**： 
  数据速率需区分“码元速率（波特率）”和“比特速率”，调制方式决定每个码元比特数；香农公式给出信道容量理论上限，两者结合可分析通信系统性能瓶颈。 
  
  ### 题目10：简述“吞吐量”与“带宽”的概念，并说明为何实际吞吐量往往低于带宽
  
  **答案**： 
- **概念**： 
- 带宽：网络链路的**理论最大数据传输速率**（如100Mbps以太网，指链路设计容量）。 
- 吞吐量：网络**实际运行中**的有效数据传输速率（如实际下载速度）。 
- **吞吐量低于带宽的原因**： 
1. **网络延迟**：数据传输、路由过程中的延迟，减少单位时间内实际传输的数据包。 
2. **丢包与重传**：数据包丢失后重传，消耗带宽资源，降低有效吞吐量。 
3. **协议开销**：网络协议（如TCP确认报文、IP头部）占用部分带宽，减少实际数据传输带宽。 
4. **网络竞争**：多用户共享带宽时，资源竞争导致每个用户实际吞吐量下降（如高峰期家庭宽带）。 
   **解析**： 
   带宽是“理论上限”，吞吐量是“实际表现”，两者差距体现网络实际性能损耗。例如100Mbps以太网，实际文件传输速率可能仅为50-80Mbps。
